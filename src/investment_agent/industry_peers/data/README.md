# Adobe-GB1 Unicode map

`Adobe-GB1-UCS2` is Adobe's unmodified standard CID-to-Unicode CMap, version 9.000.
Source: https://github.com/adobe-type-tools/mapping-resources-pdf/blob/master/pdf2unicode/Adobe-GB1-UCS2
Retrieved 2026-10-15 over verified HTTPS. SHA256:
`368b40ec05568faf323cfbbddf23c60d566bbc88e366981eb6541b026381a3b8`.

The BSD redistribution license and copyright are retained in the resource itself.
Used only for fonts declaring Adobe/GB1 + Identity-H that omit ToUnicode. It does
not replace a PDF's own mapping, OCR a page, or alter stored source bytes.
