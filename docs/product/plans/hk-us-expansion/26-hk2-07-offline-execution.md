## 接口约定

- 一家公司一份 `annual_facts`，来源 `issuer.reviewed_annual.v1`；所有实际四财年及唯一的期初权益保留原始 FactRecord。
- `payload.review` 为版本化复核索引：公司、清单哈希、核对截至日、实际最新期间、逐事实来源引用、原件持久路径、旧事实及重述计算链。导入时间是实际入库时间，不替代原件发布/抓取/核对日期。
- 汇丰派生值保留 `material.equity_reconciliation` 来源及计算输入哈希；显式标为计算证据，不能建立虚构原文摘录。
- API 增加 `freshness`、`refresh`、`metric_coverage`；保留既有状态与六能力位兼容。最近成功必须来自可核对的真实采集成功记录，离线导入不冒充线上成功。
- 当前复核选择优先于对应旧供应商版本，旧记录仍可读；新发现但未核对的年度不能被旧复核记录掩盖。
