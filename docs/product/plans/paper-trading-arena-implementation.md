## 完成标准

从 Web 创建含独立 Agent 和基准的实验，启动后由持久化任务推进。Agent 只读取冻结资料和自己的账户，结构化决策交由确定性引擎处理。相同规则和锁定订单可重建相同成交与净值；用户可回溯证据、查看复盘，暂停后不生成新交易。数据不足或规则未知明确阻塞，不虚构成交或成绩。模拟业务不写真实组合账本。
