# 行业分析扩展实施计划

日期：2026-10-15。用户授权：拆分 sub task，使用 GPT-6 Luna 子代理实施，由主代理审查与验收。当前以工作区代码为基线，保留已有港美股文档修改。

## 目标与边界

交付白酒与银行两个行业的可追溯年度离线研究闭环，以及独立行业只读入口。银行采用 run-02 的 10 家明确研究样本，不宣称完整行业；第一年度为 FY2025。候选指标为年度加权 ROE、净息差、不良贷款率、拨备覆盖率，实际覆盖和核验状态由已取得证据决定。缺少原件或语义证明的字段保持 candidate/missing，不伪造 verified。缺失不补零，不用半年报或其他年度补样本。

复用现有快照、计算、批次收据、原件与任务授权。不引入通用插件平台，不改变既有评分或筛选。在线采集启用、来源用途条件及真实外部 Agent 质量评阅是独立门禁；本次不启用生产 worker/scheduler、不改真实库、不调用真实 LLM。概念主题板块、行业评分/排行、轮动、历史投资回测延后。

## 接口约定

只支持两个显式版本指标集合：`baijiu_annual_v1`（`roe/contract_revenue/cfo_parent_profit`）与 `bank_annual_v1`（`roe/net_interest_margin/npl_ratio/provision_coverage`）。旧快照、计算、映射和研究绑定未携带集合标识时按旧白酒语义读取；新增银行必须显式标识，不能根据股票名称或任意客户端参数切换。名单 payload 保存 `metric_pack`；计算规则、批次目标映射、研究绑定保留可验证的集合关联。未知集合与混合键应拒绝。

银行三个披露比例的原始 percent 进入规范字段 `net_interest_margin/npl_ratio/provision_coverage` 后均为 fraction；`roe_weighted_annual` 继续使用既有年度加权 ROE 和归母净资产适用性证明。银行不使用白酒两项现金流/合同负债比率。指标方向仅供口径说明，不产生综合评分。

独立行业统计以固定名单和同一已提交批次为依据，行业分布包含该名单的有效公司；个股同行中位数继续排除目标，二者分别命名。至少 5 家有效公司才展示分布中位数，始终显示候选/有效数量、核验覆盖和排除原因；部分覆盖不得称完整行业。当前名单上的不同年度比较必须明确名单日期，不称历史可投资行业。原始金额汇总与整体估值留待后续，避免无依据的汇总比率。

## 验收记录

I0–I7 已完成本轮实现与主代理验收；银行按“候选事实、三项可比较、ROE 明确缺口”的实际覆盖验收，不声称四项指标均已完成原件核验。三个 GPT-6 Luna 子代理的结果已由主代理独立整链测试、代码审查、浏览器检查及完整门禁复验。

最终完整门禁分三组覆盖全部测试：3325 passed、4 skipped（外部 gateway 构建环境）、6 deselected（联网测试默认排除）；mypy 374 个源文件零错误，修改范围 Ruff 与 diff whitespace 检查通过。代理自报完成不作为单独通过依据。
