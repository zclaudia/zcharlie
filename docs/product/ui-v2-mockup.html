这次重设计要解决的问题，以及所有页面共用的 token 与组件

现状问题

  • 10 个入口平铺在顶栏，候选 → 观察 → 持仓的漏斗关系看不出来；已有的分组和图标只在移动端出现。
  • 页面宽度各不相同：AI 页撑满，其它页约 1040px 居中，1440 宽屏两侧大面积留白。
  • 三套导航 / 分页样式：顶栏胶囊、AI 页下划线 tabs、设置页左侧目录。
  • 徽章 6 种以上（灰底、橙底、橙描边、空心圆点、蓝点胶囊、紫色），按钮 5 种（含橙描边“移除”）。
  • 卡片套卡片：KPI 用彩色描边、入选理由用蓝色左边框、AI 区用淡紫底，层级靠边框而不是排版。
  • 原生控件感：“▶ + 手动提名”“▶ 详情”这类 details 三角、大段表单直接铺在页面上（持仓录入、研究方法）。
  • 单股页是一条 3 屏长的单列，AI 解释里证据 chip 密集，关键结论被淹没；顶部没有固定的股票身份栏。

v2 原则

  • 一个外壳：左侧分组侧栏（可折叠为图标）+ 顶部面包屑 + ⌘K 全局搜索；内容统一 max 1280px，AI 页全宽。
  • 漏斗即导航：侧栏“研究漏斗”组按 候选 → 观察 → 持仓 排列并带计数；概览页同样以漏斗呈现。
  • 一种页头：标题 + 一行说明 + 右侧操作；免责声明集中到侧栏底部，不再每页重复。
  • 平铺不嵌套：卡片只有一种；卡片内部用分隔线和留白分区，不再套第二层边框。
  • 收敛组件：徽章 4 色 × 实心/描边/圆点，按钮 主要/次要/幽灵 三种，分段控件统一做筛选。
  • 表单进抽屉：手动提名、录入事实、新建账户都在右侧抽屉，页面只放结果。
  • 色彩语义不变：蓝 = 主信息，橙 = 需注意，紫 = AI 生成，红涨绿跌只用于价格；全站等宽数字。
