# 个人投资 Agent 估值计算设计

日期：2026-10-10。状态：计算契约草案，尚未实现；字段覆盖和模型端点验证不在本文件中冒充完成。

A1a 提供反向 DCF 与历史估值分位两种计算能力。结果用于说明价格隐含的要求与情景敏感性，不直接输出目标价或由一个数字决定买卖。每次计算保存方法版本、事实、假设、时点、适用性与失败原因。

## 现金流与估值对象

首版反向 DCF 固定为 `reverse_dcf_fcfe.v1`：普通股股权现金流 FCFE，对应普通股整体价值，折现参数为股权要求回报。FCFE 与 FCFF 的估值对象及折现率不能混用；这项口径约束依据 [Damodaran 的估值方法说明](https://pages.stern.nyu.edu/adamodar/New_Home_Page/lectures/approach.html)。企业现金流与企业价值路线留待新增独立方法，不在同一方法中自动切换。

现有 `factors/library.py` 的 `free_cash_flow` 按经营现金流减资本开支计算。该字段本身不足以证明是可归属于普通股股东的 FCFE，不能直接接入求解器。FCFE 的一般形式为 CFO − 固定资本投资 + 净借款，并扣除未计入 CFO 的利息支付。[CFA Institute 的现金流估值定义](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/free-cash-flow-valuation)

现有东财适配器保留的现金流金额字段只有经营活动现金流量净额和购建长期资产支付的现金，另保留身份、期间与来源元数据；落库原始行也已经过此过滤。这一路径不足以推导 FCFE，不能把缺列误报为公司的现金流为零；其他来源与真实目标池覆盖须分别实测。A1a.1 先用有代表性的少量样本核对新增字段和口径，再补采适用范围；全池回填不作为公司研究闭环的前置条件，耗时与额度由实测确定。

v1 在利息列入筹资现金流、借款与发债科目不重叠且归属可统一时，按以下桥接推导：

```text
FCFE_v1 = 经营活动现金流量净额
        − 购建固定资产、无形资产和其他长期资产支付的现金
        + 取得借款收到的现金 + 发行债券收到的现金
        − 偿还债务支付的现金
        − 利息支付
```

现金流量表的“分配股利、利润或偿付利息支付的现金”合并列示现金分配与利息，仅凭此行不能拆出利息；附注或其他可核验字段可能提供拆分。[财政部对该项目的说明](https://www.mof.gov.cn/bd/mhwzzxly/hjs/202311/t20231110_3915901.htm) 利润表利息费用是应计口径，不能无条件替代实际支付；负债率低也不能证明差异不重大。v1 的正式历史输入须有现金利息或可核验的调节明细，缺失时记为缺口，不采用利息费用代理。以后若引入近似方法，须独立核验误差、标为假设情景，不能标为已核验历史 FCFE 或沿用 v1 的名称。

V3b 必须核对科目是否重叠、现金流正负号、单位、合并范围和利息是否已进入 CFO，避免重复计入债券融资或重复扣息。重大收购、处置、受限现金与再投资需求不能被简单“购建长期资产”一行掩盖；存在未处理重大差异时不适用。供应商字段映射核验后写入适配器，不由模型临时生成。首版不为补齐覆盖率另建通用会计归一化引擎。

适配器输出经核验的 `fcfe_annual`、期间、归属、调整明细与来源字段。可以读取供应商明确标识且定义已验证的 FCFE，也可以用完整字段确定性推导；两种途径有不同 derivation_version。借还款未知不能默认零，利息分类不同不能套相同公式，少数股东或优先股归属无法分清时不发布结果。公式与字段映射不能由模型临时生成。

首版只覆盖非金融、同币种、资本结构无重大未处理变化的适用公司。经营处于重大重组、现金流缺失或为负、数据口径无法统一时返回不适用。借款、还债或利息字段缺失的年度记为缺口；需要新来源时保存缺口，不把原始 FCF 改名为 FCFE。

## 输入与适用性

| 输入 | 要求 |
|---|---|
| equity_value M | 与现金流归属一致的普通股整体市值、币种和价格时点；多类股无法统一估值时不适用，不能使用流通市值。现有 `market_cap` 字段是总市值还是流通市值在 V3a 核对 |
| annual_fcfe | 截至 as_of 可得的最近三个完整年度，同口径；每期 value 与 evidence refs 齐全 |
| base_cashflow F0 | 三年中位数作为情景基数；同时展示最近一年，二者都属于已知历史值，不宣称是当期实际现金流 |
| horizon N | v1 固定 5 年；改变年限须记录为方法参数版本 |
| discount_rate r | 必填的股权回报情景假设，记录出处与选择理由；不能当作已测量的公司事实 |
| terminal_growth gT | 必填的长期现金流增长情景假设，满足 0 ≤ gT < r；来源与适用性明确 |
| sensitivity scenarios | 至少覆盖一个较高与一个较低的 r，以及最近一年与三年中位数两种 F0；不能只展示最支持原观点的一格 |

v1 的机械筛选要求三个年度 FCFE 均为正且最大值/最小值不超过 3；这个阈值是保守的方法适用范围，不证明现金流稳定或能持续。来源已有重大一次性因素、借款结构变化或股权归属问题标记时，即使比值通过也需要先解决。模型不得自行删除不利年份。

将历史年度现金流作为 as_of 的年化基数是一项显式情景假设。v1 采用从 as_of 起等距年度现金流，不处理期中存根；输出显示报告期距 as_of 的时间与该简化。原财报已逾期、现金流基础已经被新材料实质推翻或行情不符合数据时效策略时不运行正式情景。

Agent 可以在授权研究范围内提出 r 与 gT 的假设及依据，不要求用户懂估值后逐个填写。假设来源区分 `method_default、user_scenario、agent_scenario`；agent_scenario 必须展示合理性说明和敏感性，不能覆盖用户硬约束或冒充用户要求回报。无法说明假设依据时返回 `missing_assumptions`，先保留其他研究结果。

## 反向求解与输出

在给定 F0、r、gT、N 后求中期 FCFE 增长率 h：

```text
F_t = F0 × (1 + h)^t                    t = 1 … N
TV_N = F_N × (1 + gT) / (r - gT)
V(h) = Σ[t=1…N] F_t / (1+r)^t + TV_N / (1+r)^N
求解 V(h) = M
```

h 是在此简化现金流路径下匹配市值的增长要求，不是收入增长率、利润增长率或未来预测。不得直接以 h 低于历史收入增速推导“价格有吸引力”；必须另有现金转化、再投资和融资假设支持的桥接。数学求解成功不代表这些经济条件成立。输出同时给出终值现值占比，暴露结果对长期假设的依赖。

v1 用有界二分法，h 的搜索范围为 [-0.95, 1.00]，最多 200 次；有效正 F0 下 V 随 h 单调增加。终止需区间宽度不超过 1e-8 且价值相对残差不超过 1e-6，输出保存实际误差与迭代次数。金额与比率计算采用十进制，内部精度至少 28 位；显示舍入不回灌求解。

端点不能包围解时返回 `outside_search_range`，并指出匹配要求低于或高于本方法区间，不扩大区间直到得到讨喜结果。参数非法、分母非正、数值溢出或不收敛分别返回错误，不输出无穷大、NaN 或默认零。更复杂路径不沿用此方法的单调性假设。

统一返回 `status、method_version、input_refs、input_quality、assumptions、as_of、applicability、result、warnings`。status 为 ok、not_applicable、missing_inputs、missing_assumptions、stale_inputs、outside_search_range 或 calculation_error；非 ok 的 result 为 null，但保留逐情景的状态。ok 只表示计算成功，input_quality 独立呈现历史字段的核验状态，未来路径与折现参数始终标为情景假设。敏感性表中某格失败不能用相邻格补齐。

不额外减一次净债务：该方法的现金流和价值已经是股权口径。未单独估值的非经营资产、现金与其收益的处理必须在 FCFE 口径说明中一致；存在重大未处理项时标为不适用，不能重复加现金或忽略可见的重大差异。

## 历史估值分位

直接调用既有 `factors/valuation.py`，结果引用既有算法版本和输入记录，不在 Agent 中重新计算。当前契约如下，未来调整必须升版本：

- 时间窗口为 `(as_of - 5 年, as_of]`，只取可得且为正的 PE 或 PB；当前值使用 as_of 当日或之前最新交易日。
- 分位为有效序列中小于等于当前值的数量除以有效样本数，保留六位小数。
- 有效交易日少于 240 时缺失；覆盖起点落后窗口起点超过 31 天时标注 short_history 与实际覆盖年限。
- 当前值非正、缺失或财报逾期时保留既有质量标记；不能将负 PE 解读为“极便宜”。

展示有效样本数、排除的非正值、实际覆盖区间、当前价格与财报时点。PE 与 PB 解释按各自适用性进行，不能对亏损公司强行补一个 PE 分位，也不能把只有一年数据的结果简称为“五年低位”。

## 数据覆盖与验收

覆盖报告固定目标池或样本范围、版本与 as_of，先统计原始字段可得，再统计口径可用、方法适用、数值求解成功，四层分开。第一层在前置验证 V3a 用现有快照统计；后三层在 A1a.1 补采并核验后作为 V3b 统计，不在补字段前宣称反向 DCF 的覆盖，也不把样本成功率冒充全池覆盖。反向 DCF 记录 FCFE 映射、完整年度、归属、资本结构和假设缺口；分位记录有效天数、覆盖长度、负值排除与时效。每只证券可有多个原因，总体报告给出唯一主原因和全部原因明细。

A1a 的能力承诺由真实覆盖决定。数值方法在适用样本上通过验证才对该范围启用；若反向 DCF 暂无适用样本，页面明确显示未具备所需口径，首版先提供历史分位与定性研究，并在交付范围中记录限制。仅 fixture 能运行不算真实估值能力已交付，不以扩大原文接入范围或错误近似来掩盖缺口。

计算回归至少包括：等额永续现金流的可知解、提高市值或折现率后的隐含增长变化、单位换算、三个年度缺一、负现金流、未知净借款、股权口径不符、r≤gT、解超区间、逐格敏感性失败和历史分位的窗口边界。虚构验证例：F0=100、r=0.10、gT=0、N=5、M=1000，应得到 h=0；这些数值只是数学测试，不是任何公司的投资假设。

原型的公司己也是纯虚构示例：M=212.4 亿元，年度 FCFE 为 7.6、8.2、9.1 亿元，N=5，gT=2%。r=9%、F0=8.2 时，h 显示为 16.0%，终值现值占比 76.7%。r 为 8%、9%、10% 时，中位数基数对应 11.9%、16.0%、19.7%；最近一年基数对应 9.4%、13.3%、16.9%。这些是公式核对值，不能因数值可解就标记公司值得买入，也不代表真实数据适配已通过。

公式、参数、输入字段和解释文案共同版本化。新增 FCFF、分部估值或其他方法通过独立方法规格和评测加入，不能改变历史 calculation_record 的含义。
